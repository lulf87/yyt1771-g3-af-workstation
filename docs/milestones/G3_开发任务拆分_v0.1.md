# G3 开发任务拆分 v0.1

本文件把《G3 需求规格说明书 v0.1》拆成可执行 milestone。每个 milestone 都需要明确输入、输出、验收标准和 problem.md 更新。

> 2026-07-15 当前口径：产品已取消 A/C/D 业务分类，统一使用 `WHOLE_ENVELOPE + ContrastWidestSpanDetector + max_width` 和默认 8 px 窄测量带。下文 2026-06 的 A/C、Balloon/Bundle 记录是已经发生的历史里程碑事实，只用于追溯和旧数据兼容，不再定义当前产品。

### 目标

### 当前节点完成标注

```text
2026-06-04：P-0012 修复完成，A/C detector 的 Setup probe 和 Run 逐帧检测已统一为归档式稳定轮廓投影方案。
2026-06-04：P-0014 根据用户进一步确认，将归档轮廓检测拆分为 A 网格类与 C 线束类两个正式 detector 分支。

完成范围：
[x] 使用 ROI angle_deg 作为 theta。
[x] A 类 BalloonEnvelopeDetector 使用暗线增强、滞后阈值、mesh_region 和 envelope_rows 提取左右整体外包络。
[x] A 类 contour_measurement_mode = archived_mesh_envelope_rows。
[x] C 类 BundleEnvelopeDetector 使用线束分割、细长连通域保留和沿 theta 的 projection bounds。
[x] C 类 contour_measurement_mode = archived_wire_bundle_projection。
```
