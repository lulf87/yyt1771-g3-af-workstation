## 1. 总体验收原则

```text
同一 offline dataset、同一配置、同一代码版本，重复运行结果必须完全一致。
前端缩放不影响正式 distance_px。
异常帧输出 INVALID，不输出错误 A/B。
```

---

## 2. 算法验收

```text
[ ] 新建测量固定为 WHOLE_ENVELOPE + ContrastWidestSpanDetector + max_width
[ ] 对比度阈值在窄测量带内形成目标支持并输出 max-width distance_px
[ ] A/B 来自同一有效扫描行的左右整体外侧位置
[ ] A/B 点在整体外包络上
[ ] 内部缝隙不作为边界
[ ] 内部暗线 / 纹理不作为边界
[ ] 单根细支不作为正式整体目标
[ ] 夹子 / 连接丝 / 支撑丝 / 窄尾不决定 max-width
[ ] 外部 speck 不作为目标
[ ] 多个候选接近时稳定选择
[ ] rejected candidate 有 rejected_reason
```

---

## 3. UI 验收

```text
[ ] Setup 页面可加载 frame
[ ] 当前界面不提供 A/C/D 对象分类或旧 detector 选择
[ ] 新建 rotated ROI 高度默认为 measurement coordinates 下的 8 px
[ ] rotated ROI 可拖拽
[ ] 窄测量带可移动、缩放至最小 8 px 并旋转
[ ] 修改 ROI 后重新检测
[ ] A/B overlay 与后端结果一致
[ ] 诊断面板默认折叠，可展开
[ ] Playback 可逐帧查看
[ ] Live offline run 可启动停止
[ ] Analysis 曲线正确显示
[ ] Export 可下载 CSV / JSON / PNG
[ ] Operator 默认 1 个检测位置，可在运行前添加/删除，最少 1 个、最多 6 个
[ ] 只剩 1 个位置时删除禁用；只剩 1 个启用位置时禁用操作受保护
[ ] 运行中位置增删、启用、重命名和 ROI 编辑全部锁定
[ ] 当前编辑 ROI 高亮，所有启用 ROI/A/B 线按固定颜色叠加在同一帧
[ ] 实时状态按位置显示当前距离、正式点数、最近正式帧和独立失败原因
[ ] 实时与结果页按启用位置显示 1–6 条同轴温度-距离曲线，图例可切换
[ ] 结果页逐位置显示原始/平滑点数、AS、AF、ΔT、最大斜率温度和失败原因
[ ] 新多位置与旧单 ROI 导出均可在历史导入页显示
```

## 4. 温度验收

```text
[ ] 每帧保存 temperature_delta_ms
```

## 5. 真实浏览器复测最低要求

涉及 UI/流程的每次修复必须：

```text
[ ] 用真实浏览器打开页面
[ ] 使用 golden_a_20260522_dev_lab 或 golden_c_20260529_dev_lab（a/c 仅为历史 ID）
[ ] 执行相关用户流程
[ ] 截图或保存导出 artifact
[ ] 更新 problem.md
```

多检测位置改动的真实浏览器最低流程：

```text
[ ] Operator 添加至 3 个位置，分别编辑 ROI，单次 Probe 返回一张图和 3 组结果
[ ] 启动测试后位置控件锁定，3 条曲线和状态独立更新
[ ] 停止时显示逐位置分析进度，结果页显示 3 个汇总卡片和组合曲线
[ ] 导出 ZIP 检查 legacy、long、wide、regions/*.csv、analysis_by_region.json 和组合/分位置 PNG
[ ] 导入该多位置 ZIP；再导入旧单 ROI ZIP 并确认显示为位置 1
[ ] Engineering Mode 完成既有单 ROI Setup / Probe / Run / Analysis 回归
[ ] 使用 golden_a_20260522_dev_lab 与 golden_c_20260529_dev_lab 完成 Probe / Live Offline / Analysis / Export / Import
[ ] 旧 A/C measurement definition 或导出仍可读取，但新建测量仍保持统一模型
```
