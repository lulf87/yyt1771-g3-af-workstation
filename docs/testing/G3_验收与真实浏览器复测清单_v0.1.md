# G3 验收与真实浏览器复测清单 v0.1

配套阶段化测试方法：

```text
docs/testing/G3_阶段需求测试方法矩阵_v0.1.md
```

## 1. 总体验收原则

```text
同一 offline dataset、同一配置、同一代码版本，重复运行结果必须完全一致。
前端缩放不影响正式 distance_px。
异常帧输出 INVALID，不输出错误 A/B。
```

---

## 2. 算法验收

```text
[ ] A 类输出 max-width distance_px
[ ] A 类通过暗线增强 + 主体连通域 + 稳定行窗口/测量轴窗口提取左右整体外包络
[ ] A 类内部网眼、内部暗线、交叉线不作为正式边界
[ ] A 类夹子 / 连接丝 / 支撑丝 / 窄尾不决定 max-width
[ ] C 类输出 max-width distance_px
[ ] A/B 点在整体外包络上
[ ] 内部缝隙不作为边界
[ ] 内部暗线 / 纹理不作为边界
[ ] 单根细支不作为 C 类正式目标
[ ] 外部 speck 不作为目标
[ ] 多个候选接近时稳定选择
[ ] rejected candidate 有 rejected_reason
```

---

## 3. UI 验收

```text
[ ] Setup 页面可加载 frame
[ ] rotated ROI 可拖拽
[ ] 修改 ROI 后重新检测
[ ] A/B overlay 与后端结果一致
[ ] 诊断面板默认折叠，可展开
[ ] Playback 可逐帧查看
[ ] Live offline run 可启动停止
[ ] Analysis 曲线正确显示
[ ] Export 可下载 CSV / JSON / PNG
```

---

## 4. 温度验收

```text
[ ] 每帧保存 temperature_delta_ms
[ ] OK / INTERPOLATED / STALE / MISSING 状态正确
[ ] stale/missing 不进入正式 temperature-distance 曲线
[ ] 导出保留所有帧和温度状态
```

---

## 5. 真实浏览器复测最低要求

涉及 UI/流程的每次修复必须：

```text
[ ] 用真实浏览器打开页面
[ ] 使用至少一组 A 或 C 类离线数据
[ ] 执行相关用户流程
[ ] 截图或保存导出 artifact
[ ] 更新 problem.md
```

---
