# G3 离线素材注册表 v0.1

本文件记录 G3 第一阶段开发必须使用的两组真实离线素材。Codex 在开发 Offline playback、Live offline run、A/C detector、A/B 稳定策略、temperature-distance 曲线和真实浏览器复测时，必须使用这些 dataset id，而不是在代码里硬编码路径。

---

## 1. 配置文件位置

本机实际配置文件：

```text
configs/local/offline_datasets.local.json
```

示例模板：

```text
configs/examples/offline_datasets.local.example.json
```

`configs/local/offline_datasets.local.json` 可以包含开发者本机绝对路径，因此一般不建议提交到公开仓库；但在本地 Codex 开发环境中必须存在。

## 3. Dataset A：球囊 / 网状支架类

```text
Dataset ID: golden_a_20260522_dev_lab
Object class: A_BALLOON_ENVELOPE
Default detector: BalloonEnvelopeDetector
Width mode: max_width
Path: /Users/lulingfeng/Documents/工作/开发/奥氏体变换/1771/yyt1771_starter/examples/runtime/camera_captures/20260522-183158-dev_lab
```

用途：

```text
1. A 类球囊 / 网状结构整体外包络识别。
2. max-width A/B 点提取。
3. 暗线增强、主体连通域、稳定行窗口/测量轴窗口左右外包络提取验证。
4. 内部网眼、纹理、暗线、交叉线忽略规则验证。
5. 夹子、连接丝、支撑丝、窄尾不决定 max-width 的验证。
6. temperature-distance 曲线验证。
7. Offline playback 和 Live offline run 真实浏览器复测。
```

ROI 规则：

```text
真实测试时 ROI 只框有效测量主体。
底部连接丝、夹具、焊点、固定片等非测量结构不进入 ROI。
```

## 5. Codex 使用规则

Codex 必须遵守：

```text
1. 不要在 backend/frontend 代码中硬编码上述绝对路径。
2. 统一从 configs/local/offline_datasets.local.json 读取 dataset registry。
3. API 和 UI 应使用 dataset id，例如 golden_a_20260522_dev_lab。
4. 若配置文件不存在，应提示用户复制 configs/examples/offline_datasets.local.example.json 到 configs/local/offline_datasets.local.json 并修改路径。
5. 如果 dataset 路径不可访问，必须登记到 problem.md。
6. 所有 A/C detector 重要修复完成后，必须用对应 dataset 做真实浏览器复测。
```

---

## 6. 最小读取逻辑要求

后端 dataset loader 至少需要支持：

```text
load_dataset_registry(config_path)
list_offline_datasets()
resolve_dataset(dataset_id)
load_manifest(dataset_id)
load_frame(dataset_id, frame_index)
load_temperature_csv(dataset_id)
```

其中 `resolve_dataset(dataset_id)` 返回：

```text
root_path
manifest_path
temperature_csv_path
frames_dir
frame_glob
object_class
default_detector
default_width_mode
```

---

## 7. 验收要求

```text
1. Setup / Playback 页面可以列出 golden_a_20260522_dev_lab 和 golden_c_20260529_dev_lab。
2. 选择 A dataset 时默认使用 BalloonEnvelopeDetector + max_width。
3. 选择 C dataset 时默认使用 BundleEnvelopeDetector + max_width。
4. 能加载 first frame / last frame。
5. 能读取 manifest.json 中的 frame timestamp、camera_meta 和 temperature metadata。
6. 能读取 temperature.csv。
7. Live offline run 能按 5-10 fps 顺序播放并记录结果。
8. 真实浏览器复测记录必须写入 problem.md 对应条目。
```
