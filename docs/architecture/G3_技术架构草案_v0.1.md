# G3 技术架构草案 v0.1

## 1. 总体架构

```text
frontend: Vite + React + TypeScript
backend: FastAPI + Python 3.11+
vision: pure Python / OpenCV / NumPy
services: setup / playback / run / analysis / export
storage: project / run / artifact / manifest
device adapters: camera / temperature lazy import
```

## 4. 坐标边界

```text
前端显示坐标：只用于渲染和鼠标交互。
measurement coordinates：正式 ROI、A/B、distance 的唯一坐标体系。
默认 measurement coordinates：原始图像 pixel 坐标。
```

前端必须把显示坐标映射到 measurement coordinates 后提交给后端。

---

## 5. 服务边界

```text
API layer：薄层，只做请求/响应。
Service layer：业务流程。
Vision layer：纯算法。
Storage layer：读写 artifact。
Camera/temperature adapters：设备隔离，lazy import。
```

---

## 6. 关键设计约束

```text
前端不计算正式 A/B / distance。
Detector 不依赖浏览器显示坐标。
无相机也可运行 offline/playback。
历史 run 不被 re-analysis 覆盖。
```
